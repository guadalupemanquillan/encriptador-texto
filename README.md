# Encriptador de Texto – Proyecto Alura

Este proyecto es un **encriptador y desencriptador de texto** hecho con **HTML, CSS y JavaScript puro**, desarrollado como parte del *Challenge de Alura*.  
Permite encriptar y desencriptar mensajes de forma sencilla, con una interfaz moderna y responsiva.

## Características

- **Encriptar texto** usando una codificación tipo Base64 (adaptada para soportar tildes y ñ).
- **Desencriptar texto** de forma segura:
  - Si el texto no está encriptado, no lo rompe ni lo modifica.
- **Historial de operaciones**:
  - Muestra las últimas encriptaciones y desencriptaciones.
  - Indica hora, tipo de operación y textos de origen/destino.
- **Interfaz moderna y responsive**:
  - Diseño con tarjeta principal, historial lateral y colores en modo oscuro.
  - Botones que cambian de estado según si se puede encriptar o desencriptar.
- **Animación de personaje detective**:
  - Una “personita” con lupa que entra caminando por la parte inferior y se queda en una esquina.
- **Navbar y footer personalizados**:
  - Navbar fijo superior con el nombre del proyecto.
  - Footer a ancho completo con:
    - Nombre: **Guadalupe Manquillan**
    - Enlaces a **Instagram**, **GitHub**, **LinkedIn**
    - Teléfono y correo de contacto.

## Tecnologías utilizadas

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**

No se utiliza ningún framework ni bundler; es un proyecto 100% estático.

## Cómo ejecutar el proyecto

1. Clona o descarga este repositorio.
2. Abre la carpeta del proyecto.
3. Haz doble clic en el archivo `alura.html`  
   (se abrirá en tu navegador por defecto).
4. Opcional: presiona **F12** y ve a la pestaña **Console** para ver mensajes y posibles errores.

No es necesario instalar dependencias ni usar `npm start`.

## Estructura de archivos principal

- `alura.html` – Estructura de la página y maquetado general.
- `styles.css` – Estilos y diseño responsivo (layout, navbar, footer, historial, etc.).
- `alura.js` – Lógica de encriptar, desencriptar, manejo de botones y actualización del historial.
- `detective.png` – Imagen del personaje detective que se anima en la vista.
